# Hanabi Sushi (Mountain View)

Modern Next.js rebuild of [sushihanabimv.com](https://sushihanabimv.com/) - a Japanese restaurant in Mountain View, CA.

## Stack

- Next.js App Router, TypeScript, Tailwind CSS
- shadcn/ui primitives
- Deployed on Vercel

## Local development

```bash
npm install
npm run dev -- --port 43210
```

Open [http://127.0.0.1:43210](http://127.0.0.1:43210).

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Production build |
| `npm run start` | Serve the production build |
| `npm run lint` | Run ESLint |

## Content notes

Contact facts (address, phone, hours, email), logo, and photography are sourced from the live WordPress site. Online ordering links to the restaurant's Menu11 order page. The full menu PDF is available at `/menu/hanabi-2026.pdf`.
